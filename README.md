# Bus-Ticket-Reservation-System

AI Batch 36, Section F - CS Semester 1 Project.

A program designed to help users book bus tickets from a single starting stop to various selected drop-off points.

## Main Features

- **Seat Selection:** Select a seat number of your choice that has not been already booked.
- **Bus Types:** Choose from different bus classes (Economy, Executive, or Business Class).
- **Flexible Scheduling:** Choose from 3 different departure times per day.
- **Cancellation Policy:** Bookings can be cancelled with a full refund if done at least 5 hours before departure.
- **Privacy:** Personal information of passengers is kept hidden from other passengers.
- **Multiple Bookings:** Users can book multiple tickets.
